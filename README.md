# Donafresca

Site estático da Donafresca, pronto para GitHub Pages. O repositório já inclui HTML, CSS, JavaScript, imagens, catálogo, GSAP e ScrollTrigger; não há instalação ou compilação.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie **o conteúdo desta pasta para a raiz do repositório**. O arquivo `index.html` precisa aparecer na página inicial do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment → Source**, selecione **GitHub Actions**.
5. Abra a aba **Actions** e acompanhe o workflow **Publicar site**.
6. Quando o workflow terminar, o endereço aparecerá em **Settings → Pages**.

Cada `push` na branch `main` publicará a versão nova automaticamente. O workflow também pode ser executado manualmente pela aba **Actions**.

## Testar localmente

Abra `index.html` diretamente no navegador. Os arquivos do GSAP estão em `vendor/`, portanto o site não depende de CDN.
